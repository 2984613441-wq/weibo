```

5. D:\微波\ai工作区\docs\reference\external-paths.md ← COMSOL 和案例库的真实路径
```

---

## 为什么需要这段

四个 AI 的上下文互不互通。没有这段提示，新 AI 会：重读旧笔记里"没装 COMSOL"的过期结论 → 走错方向；或者在 `E:\comsol` 里直接改 `.mph` → 污染原件。

## 接进来之后

- 改 `STATUS.md` / `HANDOFF.md` 前先看 `updated` 时间戳，确认不是别人刚写的
- 结论带日期；旧结论冲突时新的优先，旧的就地标注 `⚠️ 已被 YYYY-MM-DD 版本取代`
- 同一件事有分歧：各留一句"分歧声明"（依据 + 替代方案），交用户裁决，不互相压服
