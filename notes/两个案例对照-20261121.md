## 一、一句话差别

| | microwave_oven | rf_heating |
|---|---|---|
| 一句话 | 微波炉里烤一个土豆，**单向**耦合 | 弯曲波导里加热一个介质块，**双向**耦合 |
| 耦合方式 | 频域电磁 → 瞬态传热，**单向**（物性假设不随温度变） | 电磁 ↔ 传热**双向**（损耗角正切和导热系数随温度变） |
| 学习价值 | 先跑通：结构简单、耦合单 | 再进阶：多物理场反馈、两种研究类型 |

## 二、参数对照

| 项 | microwave_oven | rf_heating |
|---|---|---|
| 频率 | 2.45 GHz | 10 GHz |
| 功率 | 1 kW（对称减半后输入 500 W） | 100 W |
| 激励 | 矩形波导 TE10 模式 | 矩形波导 TE10 模式 |
| 结构 | 金属腔 + 波导馈电 + 玻璃板 + 球形土豆 | 弯曲波导 + 内嵌电介质块 |
| 壁材料 | 铜 + 阻抗边界条件（含表面损耗） | 铝 + 内壁铜涂层（集肤深度远小于尺寸 → 不求解壁内麦克斯韦方程） |
| 对称性 | 垂直对称切半（利用镜像对称，n×H=0） | 无对称简化 |
| 介质物性 | 土豆，假设**不随温度变化** | σ=0，μr=1，εr=2.1，**tanδ=0.001(T/300K)**，**k=0.3(T/300K)** W/(m·K)，ρ=2200 kg/m³，Cp=1050 J/(kg·K) |
| 热边界 | — | 介质块与壁完全热接触；外壁自然对流（平均 h） |
| 研究类型 | 频域 → 瞬态传热（单向） | 频域-瞬态 或 频域-稳态（双向） |
| 案例库路径 | `RF_Module/Microwave_Heating/microwave_oven` | `RF_Module/Microwave_Heating/rf_heating` |

## 三、文档给出的关键结论（可作为验证目标）

**microwave_oven**

- 土豆吸收约 **60%** 输入微波功率，其余大部分从端口反射回来
- 中心温度峰值明显 → 土豆充当微波场的**谐振腔**，形成复杂振荡模式
- 加热 5 秒时中心已出现高峰值（因为土豆导热系数低，热量扩散慢）
- 继续加热到 100 ℃ 时水分沸腾、中心干燥、蒸汽传热、电磁属性改变——**本模型没有捕捉这些非线性效应**，只作为更高级分析的起点

**rf_heating**

- 电介质块需要**几分钟**才能升温（图 2 为最高温度随时间曲线）
- 集肤深度远小于波导尺寸 → 电磁损耗完全集中在表面 → **只解空气域和介质块内的麦克斯韦方程**
- 频域-稳态 比 频域-瞬态 快，但拿不到瞬态信息

## 四、怎么用这篇对照

1. **先做 microwave_oven**：结构简单、单向耦合，先验证"能不能跑出 60% 吸收功率"这个官方数字——这是最好的正确性检查
2. **再做 rf_heating**：引入温度依赖物性，观察双向耦合与单向耦合的差别，并对比 频域-瞬态 vs 频域-稳态 的耗时与结果
3. **两个都跑通后**，才谈"改成自己的对象"
