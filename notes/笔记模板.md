# 笔记模板

> 一个案例一篇，文件名 `<案例名>-<主题>.md`，例：`microwave-oven-第一遍复现.md`。
> **同名不覆盖**：同主题再写就加日期后缀。

## 一、5 行格式（每个案例结束时必须写）

```markdown
## <案例名> · <日期>

- 现象：结果长什么样（温度峰值 / 场分布 / 散射参数）
- 关键设置：哪 1~3 个设置决定了这个结果
- 坑：这次踩到的、下次会再踩的
- 结果：关键数值 + 图在哪
- 疑问：还不确定的，留给下次或问人
```

## 二、复现时的七步骨架（照这个顺序定位问题）

|- 步 | 模型树位置 | 这次做了什么决定 | 打勾 |
|---|---|---|---|
| 1 几何 | 组件 → 几何 | | ☐ |
| 2 定义 | 全局定义 / 组件定义 | | ☐ |
| 3 材料 | 组件 → 材料 | | ☐ |
| 4 物理场 | 组件 → 物理场 | | ☐ |
| 5 网格 | 组件 → 网格 | | ☐ |
| 6 求解 | 研究 | | ☐ |
| 7 后处理 | 结果 | | ☐ |

> 来源：用户既有笔记 `02-学习路线-4周.md` 的七步骨架。**结果不对时按这七步的顺序排查，不要乱改参数。**

## 三、微波加热专用检查项

复现 `microwave_oven` / `rf_heating` 时，逐条确认并在笔记里记下实际值：

- [ ] 激励：端口类型（同轴 / 波导）、功率（W）、频率（GHz）
- [ ] 边界：PML 还是散射边界？厚度取了几何尺度的多少倍？
- [ ] 材料：介电常数是常数还是温度/频率相关（`epsilon_r(T)`）？
- [ ] 耦合：电磁热是**单向**还是**双向**（是否回写温度到介电损耗）？
- [ ] 网格：最大单元尺寸 ≤ λ/6 吗？PML 区单独扫掠网格了吗？
- [ ] 求解：先频域稳态电磁 → 再瞬态传热，还是全耦合？
- [ ] 后处理：热点温度、SAR、反射系数 S11 三个量对得上吗？
